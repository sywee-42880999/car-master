# CAR MASTER v0.4

현대자동차 공식 영문 용어로 배우는 모바일 우선 자동차 파트 학습 앱입니다.

## 구성

- 실제 all-new Hyundai VENUE 전면·후면·측면 이미지
- 4개 외장 파트 학습: `Hood`, `Headlamps`, `Tires and wheels`, `Outside rearview mirrors`
- 실제 이미지의 파란 위치 표시를 이용한 4지선다
- 이미지·설명·위치를 섞은 8문제 혼합 테스트
- 누적 점수 및 Rookie / Driver / Expert / Master 등급
- iPhone safe-area 및 320px 화면 대응

## 용어 기준

- Hyundai Owner's Manual — Exterior Overview
- Hyundai Global Product Information — all-new VENUE

문제와 설명은 한글로 제공하며, 학습 대상 자동차 용어만 공식 영어 표기를 사용합니다.
