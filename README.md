# CAR MASTER v0.3

English, mobile-first vehicle parts learning app built as a serverless PWA for GitHub Pages.

## Included

- Four exterior learn items: Hood, Headlamp, Wheel & Tire, Side Mirror
- Four-choice test
- Eight-question mixed test using term, location, and description prompts
- Persistent local score with Rookie, Driver, Expert, and Master ratings
- iPhone-safe responsive layout with no external runtime dependencies
- Offline cache through a service worker
