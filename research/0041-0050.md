# CAR MASTER Research 0041–0050

Status: RESEARCH ONLY. Do not increase production completion % until final learning crops are live in BLACK UI.

Primary baseline: Hyundai official Owner's Manual terminology. Prefer terms repeated across current Hyundai models. Keep model/regional variants as aliases rather than silently replacing the permanent master term.

## Proposed candidates

0041 GLOVE BOX / 글로브 박스
- Strong official term across 2026 Palisade, 2026 Tucson, 2025 IONIQ 5.
- Palisade center console overview: https://ownersmanual.hyundai.com/full_webhelp/LX3/2026/en_US/picture_index_center_console_overview.html
- Tucson center console overview: https://ownersmanual.hyundai.com/full_webhelp/NX4a/2026/en_US/idc36dcc009e2.html
- IONIQ 5 center console overview: https://ownersmanual.hyundai.com/full_webhelp/NE1a/2025/en_US/id6393b0a350e.html
- Recommended status: PASS CANDIDATE.

0042 CENTER CONSOLE / 센터 콘솔
- Official term appears across Palisade and IONIQ 5. Tucson often labels CENTER CONSOLE STORAGE for the storage compartment itself.
- Keep physical console vs storage compartment distinction in QA.
- Recommended status: PASS CANDIDATE, alias/relation: CENTER CONSOLE STORAGE.

0043 CUP HOLDER / 컵 홀더
- Official 2026 Hyundai terminology, repeated across Palisade/Tucson and other current models.
- Palisade Interior Features: https://ownersmanual.hyundai.com/full_webhelp/LX3/2026/en_US/idcf7535ebdb6.html
- Tucson Interior Features: https://ownersmanual.hyundai.com/full_webhelp/NX4a/2026/en_US/idcf7535ebdb6.html
- Recommended status: PASS CANDIDATE.

0044 USB PORT / USB 단자
- Palisade center console overview explicitly labels USB port.
- IONIQ 5 uses USB port / charger and separate charger terms depending on function.
- Do not merge data/media USB PORT with charge-only USB CHARGER/USB CHARGING TERMINAL.
- Recommended status: PASS CANDIDATE.

0045 USB CHARGER / USB 충전 단자
- Current Hyundai manuals distinguish USB CHARGER from USB PORT on several models.
- Tucson center console overview labels Rear USB charger and USB Charger.
- IONIQ 5 labels Front seat USB charger / Rear seat USB charger.
- Recommended status: PASS CANDIDATE; keep separate from 0044.

0046 POWER OUTLET / 다용도 소켓
- Official current Hyundai term across Palisade, Tucson, IONIQ 5.
- Recommended status: PASS CANDIDATE.

0047 WIRELESS SMARTPHONE CHARGING SYSTEM / 스마트폰 무선 충전 시스템
- Exact official Hyundai term across Palisade/Tucson/IONIQ.
- Physical target should be charging pad/system area, not only indicator lamp.
- Recommended status: PASS CANDIDATE.

0048 HAZARD WARNING FLASHER BUTTON / 비상경고등 버튼
- Palisade/Tucson official wording uses Hazard warning flasher button; some models use switch.
- Alias: HAZARD WARNING FLASHER SWITCH.
- Recommended status: PASS CANDIDATE with alias review.

0049 ENGINE START/STOP BUTTON / 시동 버튼
- Palisade/Tucson official wording: Engine Start/Stop button.
- IONIQ/EV manuals may use Start/Stop button without “Engine”.
- Because EV taxonomy differs, keep aliases/model scope visible. Do not force ENGINE wording onto EV.
- Recommended status: REVIEW for permanent canonical wording; likely canonical family: START/STOP BUTTON with ENGINE START/STOP BUTTON alias for ICE/HEV.

0050 INSTRUMENT CLUSTER / 계기판
- Exact current Hyundai term across Palisade, Tucson, IONIQ 5.
- Recommended status: PASS CANDIDATE.
