# CAR MASTER Research 0051–0060

Primary baseline: Hyundai 2026 Palisade LX3 official Owner's Manual, Center Console Overview.

Source:
- https://ownersmanual.hyundai.com/full_webhelp/LX3/2026/en_US/picture_index_center_console_overview.html

Candidate allocation:

- 0051 HORN / 혼
  - Official label on Center Console Overview: Horn
  - Strong common physical-part term.
  - Status: PASS-CANDIDATE

- 0052 INFOTAINMENT SYSTEM / 인포테인먼트 시스템
  - Official label: Infotainment system
  - Broad assembly; later image should show the display/head-unit area, not software UI alone.
  - Status: PASS-CANDIDATE

- 0053 CLIMATE CONTROL SYSTEM / 공조 시스템
  - Official label: Climate control system
  - Broad control assembly; distinguish from individual temperature/fan controls which may get separate IDs later.
  - Status: PASS-CANDIDATE

- 0054 AUTO HOLD BUTTON / 오토 홀드 버튼
  - Official Center Console Overview label: Auto Hold button
  - Dedicated page: https://ownersmanual.hyundai.com/full_webhelp/LX3/2026/en_US/id43680d1d7f8.html
  - Image key on dedicated page: 2C_AutoHoldButtonOnOff
  - Status: PASS-CANDIDATE

- 0055 DRIVE MODE CONTROL / 드라이브 모드 조작부
  - Official Center Console Overview wording: Terrain mode, Drive mode integrated control system
  - Taxonomy caution: physical switch/control vs whole integrated control system.
  - Keep as REVIEW until exact physical-part naming is fixed across models.
  - Status: REVIEW

- 0056 DOWNHILL BRAKE CONTROL BUTTON / 경사로 저속 주행 버튼
  - Official Center Console Overview wording: DBC (Downhill brake control) button
  - Physical button is visually distinct.
  - Status: PASS-CANDIDATE

- 0057 PARKING SAFETY BUTTON / 주차 안전 버튼
  - Official Center Console Overview label: Parking Safety button
  - Linked function: Parking Distance Warning (PDW)
  - Important distinction from 0027 parking ultrasonic sensor: this ID is the interior control button, not the exterior sensor.
  - Status: PASS-CANDIDATE

- 0058 PARKING/VIEW BUTTON / 주차/뷰 버튼
  - Official Center Console Overview label: Parking/View button
  - Linked functions: Rear View Monitor (RVM), Surround View Monitor operation.
  - Status: PASS-CANDIDATE

- 0059 UV-C STERILIZER SYSTEM / UV-C 살균 시스템
  - Official Center Console Overview label: UV-C sterilizer system
  - Model/trim-specific; useful vocabulary but should preserve 'if equipped' context.
  - Status: PASS-CANDIDATE

- 0060 AC INVERTER / AC 인버터
  - Official Center Console Overview label: AC 115V inverter
  - Use generic master label AC INVERTER with alias 'AC 115V INVERTER' unless regional source standardizes another voltage.
  - Status: PASS-CANDIDATE

General QA:
- 0054 is AUTO HOLD BUTTON, not the Auto Hold system itself.
- 0057 is an interior button and must never be confused with 0027 ultrasonic sensor(s).
- 0058 is a camera/view control button and must not be confused with 0017 rear camera hardware.
- 0055 remains REVIEW because Hyundai wording varies between Drive Mode / Terrain Mode / integrated control system across models.
- 0059/0060 are trim-dependent but legitimate physical vocabulary items.
- Final ID insertion into master.json should occur only after duplicate/alias check and source registration.
