## Alias / duplicate rules

- 0091 `LIGHTING CONTROL LEVER` is a control stalk, not `HEADLIGHTS` or `TURN SIGNAL LIGHT`.
- 0092 `WIPER AND WASHER CONTROL LEVER` is a stalk, not a wiper blade.
- 0093 uses plural in master because two physical paddle shifters are present. Preserve official singular `Paddle shifter` as source label/alias.
- 0095: `CLUSTER DISPLAY CONTROLS BUTTON` / `CLUSTER DISPLAY CONTROL` / `LCD DISPLAY CONTROL` are model/region variants. Do not create separate IDs unless the physical hardware is materially different.
- 0097 is the visible physical button; `Lane Keeping Assist` and `Lane Following Assist` are functions, not synonyms for the button itself.
- 0098 `ROTARY GEAR SHIFT DIAL` and `ROTARY SHIFTER` refer to the same physical control in different manuals; alias them.
- 0099 `STEERING WHEEL AUDIO CONTROLS` and `AUDIO REMOTE CONTROL BUTTONS` are aliases for the same physical control group.
- 0100 must not share an image with `BLUETOOTH HANDS-FREE PHONE BUTTON`; that should get its own ID in a later batch.
- Existing 0051 `HORN` and 0039 `STEERING WHEEL` are not duplicated in this batch.
