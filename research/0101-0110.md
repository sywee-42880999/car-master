## Alias / duplicate rules

- 0101: `BLUETOOTH® HANDS-FREE PHONE BUTTON` is the current US master candidate; `Bluetooth wireless technology hands-free button` is an alias from another Hyundai US manual.
- 0102 IN-CABIN CAMERA is a driver-monitoring interior camera. Never reuse exterior camera imagery from 0010 or 0017.
- 0103 DRIVE MODE BUTTON is a visible button. 0055 DRIVE MODE CONTROL is a broader control/system candidate; if later QA proves 0055 represents the same physical control, mark one REVIEW rather than silently merging IDs.
- 0104 TERRAIN MODE BUTTON is separate from DRIVE MODE BUTTON even when functions are integrated in one control cluster on some models.
- 0105 and 0106 are N-specific and should only use N-model imagery.
- 0108 VANITY MIRROR and 0088 VANITY MIRROR LAMP are different physical parts.
- 0110 SUNROOF SWITCH and 0006 SUNROOF are not duplicates: control vs roof opening/glass assembly.

## Image-production handoff

1. For 0101–0106, use the official embedded steering-wheel overview source, then crop each physical control distinctly. N1/N2 and NGB must use NE1N source only.
2. For 0102, prefer a close crop around the in-cabin camera housing. No marker if unmistakable.
3. For 0107–0109, use `2C_Sunvisor`; create three different crops so the sunvisor, vanity mirror, and ticket holder are visually unambiguous.
4. For 0110, use `2C_SunroofButtonOverview` or a more dedicated official image if available. Teach the switch, not the glass roof.
5. Close-up = no red marker. Context image = HTML overlay marker only; never bake marker into JPG.
6. Reverse QA: English term → exact physical item → final image → marker/close-up.
7. Ambiguous result => REVIEW, not PASS.
