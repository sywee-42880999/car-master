## Alias / duplicate rules

- 0111 CENTER CONSOLE STORAGE is not the same as 0042 CENTER CONSOLE. 0042 = console assembly; 0111 = storage compartment within/at console.
- 0112 OPEN TRAY and 0113 SLIDING TRAY are separate physical storage parts.
- 0114 CARGO TRAY must not be merged with cargo floor, cargo board, luggage board, or under-floor storage if those are added later.
- 0116 REAR SIDE SUNSHADE aliases: `REAR SIDE WINDOW SUNSHADE(S)` where used by other Hyundai manuals.
- 0117 teaches the holder/anchor. If `CARGO NET` is added later, give it its own ID only when the net itself is the target.
- 0118 aliases may include `LUGGAGE SCREEN` / `LUGGAGE COMPARTMENT COVER` depending on region, but physical equivalence must be visually QA'd before merging.
- 0119 master plural follows the project rule for multiple identical parts. Official singular/`Anchor(s)` wording remains searchable alias.
- 0120 is the dedicated power-sunshade control, not the sunshade fabric/panel and not the generic sunroof switch.
