## Candidate IDs

### 0161 — BRAKE DISC / 브레이크 디스크
Status: CANDIDATE
- Official Hyundai wording confirmed.
- Distinguish from 0160 BRAKE PAD.
- Alias note: some manuals also use ROTOR in the same maintenance grouping; do not create a second permanent ID unless Hyundai source clearly treats the physical item separately for the specific vehicle.
- Visual: wheel-off close-up preferred; no marker if disc is clearly isolated.

### 0162 — BRAKE CALIPER / 브레이크 캘리퍼
Status: CANDIDATE
- Official Hyundai wording confirmed as “calipers.”
- Physical component visually distinct from brake disc and pad.
- Master singular because each learning card identifies one component; plural source wording retained as alias/source form.

### 0163 — STEERING GEAR RACK / 스티어링 기어 랙
Status: CANDIDATE
- Official Hyundai wording: “Steering gear rack, linkage and boots.”
- Keep separate from STEERING WHEEL 0039 and steering-wheel controls.
- Undercarriage/service illustration likely required.

### 0164 — STEERING LINKAGE / 스티어링 링키지
Status: REVIEW
- Hyundai groups “rack, linkage and boots” in maintenance wording.
- “Linkage” can refer to multiple connected steering pieces rather than one visually isolated part.
- Require a Hyundai diagram or service-style illustration that clearly identifies the component before PASS.

### 0165 — STEERING GEAR BOOT / 스티어링 기어 부트
Status: REVIEW

- Need direct Hyundai visual confirmation of the exact boot before PASS.

### 0166 — DRIVESHAFT / 드라이브샤프트

### 0167 — DRIVESHAFT BOOT / 드라이브샤프트 부트
Status: CANDIDATE

### 0168 — SUSPENSION BALL JOINT / 서스펜션 볼 조인트

### 0169 — PROPELLER SHAFT / 프로펠러 샤프트
Status: CANDIDATE
- Official Hyundai wording confirmed.
