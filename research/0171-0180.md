# CAR MASTER Research — IDs 0171–0180

Status: RESEARCH ONLY. Do not increase production completion until final learning images are cropped, QA’d, bound to permanent IDs, and deployed in the BLACK UI.

Primary source of truth: Hyundai official Owner’s Manual terminology. This batch extends underbody / drivetrain / suspension taxonomy. Exact model-specific imagery must be verified before Production PASS.

## Candidate IDs

### 0171 — FRONT DIFFERENTIAL / 프론트 디퍼렌셜
Status: REVIEW
- Physical drivetrain component for applicable AWD layouts.
- Must be supported by a model-specific Hyundai official diagram before PASS.
- Do not confuse with transfer case or transaxle.

### 0172 — TRANSFER CASE / 트랜스퍼 케이스
Status: CANDIDATE
- Hyundai maintenance terminology uses “Transfer case oil (AWD)”.
- Master term normalized to physical component TRANSFER CASE.
- AWD-specific imagery required.

### 0173 — FRONT SUSPENSION / 프론트 서스펜션
Status: REVIEW
- Broad assembly-level term.
- Keep only if CAR MASTER intentionally includes assemblies as well as individual components.
- Final image must clearly communicate the whole front suspension assembly.

### 0174 — REAR SUSPENSION / 리어 서스펜션
Status: REVIEW
- Broad assembly-level term; same taxonomy issue as 0173.
- Model-specific rear suspension layout varies.

### 0175 — SHOCK ABSORBER / 쇼크 업소버
Status: CANDIDATE
- Common Hyundai service/vehicle terminology.
- Visually distinct damper component.
- Do not use STRUT as an automatic synonym; architecture differs.

### 0176 — COIL SPRING / 코일 스프링
Status: CANDIDATE
- Distinct suspension spring component.
- Close-up preferred; no marker if isolated.

### 0177 — STABILIZER BAR / 스태빌라이저 바
Status: CANDIDATE
- Suspension anti-roll component.
- Alias note: sway bar / anti-roll bar are common industry terms, but Hyundai source wording should control final English label.

### 0178 — LOWER CONTROL ARM / 로어 컨트롤 암
Status: CANDIDATE
- Distinct suspension link/control arm.
- Require Hyundai diagram or sufficiently clear official underbody image.

### 0179 — TIE ROD END / 타이로드 엔드
Status: CANDIDATE
- Steering linkage endpoint; visually distinct from steering rack and suspension ball joint.
- Reverse QA mandatory because it can be confused with ball joint in poor imagery.

### 0180 — WHEEL HUB / 휠 허브
Status: CANDIDATE
- Wheel mounting/hub component.
- Distinguish from WHEEL 0008, wheel bearing, brake disc and wheel studs.

## Duplicate / taxonomy QA

- 0171 FRONT DIFFERENTIAL vs 0170 REAR DIFFERENTIAL: location-specific separate components; 0171 remains REVIEW until official model-specific source is secured.
- 0172 TRANSFER CASE is not the same physical object as differential or transaxle.
- 0173/0174 are assembly-level terms and may be excluded later if the final taxonomy is component-only.
- 0175 SHOCK ABSORBER and STRUT must not be merged without model-specific confirmation.
- 0178 LOWER CONTROL ARM, 0179 TIE ROD END and 0168 SUSPENSION BALL JOINT must have distinct reverse-QA images.
- 0180 WHEEL HUB is not WHEEL 0008.

## Image handoff to Codex / Work

1. Use Hyundai official Owner’s Manual / official technical diagrams first.
2. Underbody parts need tight crops; whole-car images are weak learning assets.
3. Do not guess a component from a generic underbody photo.
4. If a component cannot be positively identified, leave REVIEW and move to the next ID.
5. Marker only as HTML overlay when context is necessary; never bake marker into image.
6. Source image → final 4:3 crop → permanent ID binding → BLACK UI deploy → only then Production completion.
7. Do not increment production progress for this research commit.
