Primary terminology policy: Hyundai official Owner’s Manual wording first. Batch theme: instrument cluster / driver-information hardware and dashboard components.

## Candidate IDs

### 0271 — SPEEDOMETER / 속도계
Status: CANDIDATE
- Vehicle-speed display/gauge in instrument cluster.
- Digital or analog implementation may vary.

### 0272 — TACHOMETER / 타코미터
Status: CANDIDATE
- Engine RPM gauge/display on ICE/HEV models where equipped.
- Not applicable to EV-only clusters.

### 0273 — FUEL GAUGE / 연료 게이지
Status: CANDIDATE
- Fuel level display for fuel-powered models.
- Keep distinct from EV battery state-of-charge display.

### 0274 — ODOMETER / 적산거리계
Status: CANDIDATE
- Total accumulated vehicle mileage display.
- Distinguish from trip computer/trip meter.

### 0275 — TRIP COMPUTER / 트립 컴퓨터
Status: REVIEW
- System/information-page concept rather than a single physical component.
- Retain only if learning taxonomy includes display functions as well as physical parts.

### 0276 — WARNING LIGHT / 경고등
Status: REVIEW
- Generic umbrella term; may be too broad for permanent visual-part taxonomy.
- Prefer individual warning indicators later if useful.

### 0277 — TURN SIGNAL INDICATOR / 방향지시 표시등
Status: CANDIDATE
- Instrument-cluster indicator, not exterior 0028 TURN SIGNAL LIGHT.

### 0278 — GEAR POSITION INDICATOR / 변속 위치 표시
Status: CANDIDATE
- Cluster/display indication of selected gear position.
- Distinguish from 0098 ROTARY GEAR SHIFT DIAL physical selector.

### 0279 — DRIVER INFORMATION DISPLAY / 운전자 정보 디스플레이
Status: REVIEW
- Hyundai naming varies by generation/model (cluster display, LCD display, etc.).
- Potential overlap with 0050 INSTRUMENT CLUSTER and 0095 CLUSTER DISPLAY CONTROL BUTTON.

### 0280 — DASHBOARD / 대시보드
Status: CANDIDATE
- Broad physical instrument-panel/dashboard structure.
- Final source should clearly show the dashboard as a physical cabin component, not just electronics.
